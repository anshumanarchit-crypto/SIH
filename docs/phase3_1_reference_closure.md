## 5. Validation Architecture Changes

Validation infrastructure was updated to consume the external reference truth while maintaining strict production isolation:

1. **Manifest Registration**:
   - Added `"reference_bits"` metadata to `data/official/sinchana/official_manifest.json` recording filename, bit count, SHA-256 hash, and provenance package.
2. **Reference Resolution in Generator**:
   - Updated `scripts/generate_official_validation_results.py` to route G1 and G5 uncoded reference ingestion to `data/official/sinchana/reference_bits/`, while preserving `data/handoff/` for cases G2–G7.
3. **Bit Alignment & Length Pre-flight Verification**:
   - Added explicit length match checks between demodulated bitstream and reference bits: if lengths differ, validation fails explicitly with `ValueError`.
4. **QPSK Demapping Constellation Profile**:
   - Added `MAPPING_PROFILES_QPSK = {"DEFAULT": "IQ", "OCTAVE": "QI"}` in `python/spectralq/demod.py` to support GNU Octave QPSK bit ordering (`OCTAVE`), matching existing `8PSK` and `16QAM` design patterns.
5. **Phase-Ambiguity Aware BER Evaluation**:
   - Updated `python/spectralq/decoder_api.py` to calculate final reference BER using `chosen_bits` post-phase ambiguity resolution rather than unrotated nominal decisions.
6. **Phase 3 Evidence & Confidence Ledger**:
   - In `python/spectralq/bitintel.py`, recorded `EVID_REF_AVAILABLE`, `EVID_REF_BIT_COUNT`, `EVID_DEMOD_BIT_ERRORS`, and `EVID_REF_BER`.
   - In `python/spectralq/confidence.py`, enabled dynamic weight (0.15) for `reference_support` when external reference bits are evaluated.
