# SpectralQ Demodulator Core (Phase 2)

## 1. Overview & System Scope

The Demodulation Core (`spectralq.demod`) converts complex baseband IQ waveforms into recovered digital symbol decisions, hard bits, and factual physical-layer diagnostics.

### Strict Team Boundaries
- **Arpit (Demodulator & Decoder Core)**: RRC matched filtering, symbol timing recovery, carrier synchronization, phase ambiguity resolution, FSK discrimination, constellation slicing, and pipeline integration.
- **Archit (Hypothesis & Evidence Engine)**: Confidence scoring, hypothesis ranking, and `UNKNOWN` classification. The demodulator **does not** compute confidence or decide `UNKNOWN`.
- **Sinchana (Octave DSP & Waveform Generation)**: Official `.cf32` capture generation, Octave estimators, and official golden waveform truth datasets.
- **Harsh (ML Classifier)**: Modulation classification, blind sweeps.
- **Himanshu (UI)**: Streamlit GUI visualization.

### Verification Status Classification
> [!IMPORTANT]
> - **SYNTHETIC DEVELOPMENT TESTS**: Fast, deterministic, test-only fixtures generated by `tests/fixtures/synthetic_generator.py`. Labeled `TEST FIXTURE ONLY — NOT OFFICIAL GOLDEN DATA`. Used solely for verifying algorithm mathematics and synchronization loops.
> - **OFFICIAL OCTAVE GOLDEN TESTS**: Waveform captures (`.cf32`, `.meta.json`, `truth.json`) generated independently by Sinchana. These files validate project-level compliance once received.

## 2. Supported Modulations & Constellations

All PSK and QAM bit mappings adhere to standard Gray mapping definitions:

| Modulation | Order $M$ | Bits/Sym | Slicing / Discriminator Strategy |
|---|---|---|---|
| **BPSK** | 2 | 1 | Real-axis thresholding ($\pm 1$), Gray mapped $\{0, 1\}$. |
| **QPSK** | 4 | 2 | Quadrant slicing ($\pm 1 \pm j$), Gray mapped $\{00, 01, 11, 10\}$. |
| **8-PSK** | 8 | 3 | Angular sector slicing ($k \pi/4$), Gray mapped. |
| **16-QAM** | 16 | 4 | 2D rectangular grid slicing ($\pm 1, \pm 3$). |
| **64-QAM** | 64 | 6 | 2D rectangular grid slicing ($\pm 1, \pm 3, \pm 5, \pm 7$). |
| **2-FSK** | 2 | 1 | Phase-difference instantaneous frequency discriminator with integrate-and-dump. |
| **4-FSK** | 4 | 2 | Phase-difference instantaneous frequency discriminator with 4-level quantization. |

## 3. Demodulator Pipeline & Algorithms

### A. Root-Raised-Cosine (RRC) Matched Filter
- **Taps Generation**: `rrc_filter_taps(sps, span_symbols, roll_off)`
- **Singular Points**: Special handling at $t = 0$ and $t = \pm T_s / (4 \alpha)$ to avoid $0/0$ numerical divergence.
- **Energy Normalization**: Taps are normalized such that $\sum |h[n]|^2 = 1.0$.
- **Delay Accounting**: Group delay is exactly `(span_symbols * sps) // 2` samples. Downstream recovery accounts for filter transient settling.

### B. Gardner Timing Recovery
- **Detector**: Non-data-aided Gardner Timing Error Detector (TED):
  $$e[k] = \text{Re}\{(y_k - y_{k-1}) \cdot y_{k-1/2}^*\}$$
- **Interpolation**: 4-point Hermite cubic polynomial interpolator supporting continuous fractional delay $\mu \in [0, 1)$.
- **Loop Filter**: Proportional-Integral (PI) loop filter adjusting fractional phase increment:
  $$\Delta t = \text{sps} - (K_p \cdot e[k] + v[k])$$
- **Assumptions & Operating Limits**:
  - Requires $sps \ge 2.0$ (typically $sps = 4$ or $8$).
  - Tolerates fractional clock offsets within $\pm 5\%$.
  - Operates reliably down to $E_b/N_0 \approx 4\text{ dB}$.

### C. Carrier Recovery (M-PSK)
- **Coarse CFO Estimation**: M-th power frequency offset estimation:
  $$\hat{\omega}_{\text{cfo}} = \frac{1}{M} \arg\left(\sum_{n} (r[n])^M \cdot (r[n-1]^M)^*\right)$$
- **Fine Tracking (Decision-Directed Costas Loop)**:
  - Error: $e_c = \text{Im}\{y \cdot d^*\}$ where $d = \text{slice}(y)$.
  - 2nd-order loop filter updating phase accumulator $\theta[k]$.

### D. Phase Ambiguity Resolution
- M-PSK carrier recovery exhibits an $M$-fold rotational phase ambiguity ($k \cdot 2\pi/M$).
- When a known preamble / sync sequence is configured:
  1. The demodulator tests all $M$ candidate rotations: $\phi_k = k \frac{2\pi}{M}$.
  2. Slices bits and correlates against the known preamble.
  3. Selects the candidate with the highest preamble correlation.
  4. If peak correlation is below threshold, marks `status = LOW_QUALITY` and sets a warning.

### E. FSK Demodulator (Discriminator Path)
- **Phase Difference Discriminator**:
  $$\Delta \theta[n] = \arg\left(r[n] \cdot r[n-1]^*\right)$$
- **Frequency Offset Estimation**: Center frequency is estimated using symmetric extreme percentiles $(P_{10} + P_{90}) / 2$, which is robust to bit imbalance ($\Delta N / N \ne 0$).
- **Integrate-and-Dump Filter**: Averages instantaneous frequency deviations over the nominal symbol period $sps$.
- **Quantization & Gray Mapping**: Slices decision statistics into $M$ frequency states.

## 4. API & Typed Contract

### Input Configuration (`DemodConfig`)
```python
@dataclass
class DemodConfig:
    modulation: str = "QPSK"           # "BPSK", "QPSK", "8-PSK", "16-QAM", "2-FSK", "4-FSK"
    samples_per_symbol: float = 4.0    # Oversampling ratio
    sample_rate: Optional[float] = None # Hz (if known)
    symbol_rate: Optional[float] = None # Baud (if known)
    roll_off: float = 0.35             # RRC excess bandwidth alpha
    filter_span_symbols: int = 8       # RRC filter span
    preamble_bits: Optional[np.ndarray] = None # For phase ambiguity resolution
    fsk_deviation: Optional[float] = None # Peak frequency deviation (Hz or rad/sample)
```

### Result Object (`DemodResult`)
```python
@dataclass
class DemodResult:
    status: DemodStatus                # SUCCESS, LOW_QUALITY, NON_CONVERGED, INVALID_INPUT, etc.
    modulation: str
    input_sample_count: int
    output_symbol_count: int
    output_bit_count: int
    samples_per_symbol_used: int
    timing_status: Dict[str, Any]      # converged, jitter, mean_step, final_delay
    carrier_status: Dict[str, Any]     # converged, coarse_cfo_rad, fine_cfo_rad, ambiguity
    estimated_frequency_offset: float  # Radians/sample
    estimated_phase_offset: float      # Radians
    timing_error_summary: Dict[str, Any]
    symbol_decisions: np.ndarray       # Complex/real symbol array
    hard_bits: np.ndarray              # uint8 bit array
    soft_bits: Optional[np.ndarray]    # LLRs where supported
    mapping_profile_used: str = "DEFAULT" # Mapping profile name ("DEFAULT", "OCTAVE")
    candidate_rotations: List[Dict[str, Any]] = field(default_factory=list) # Phase candidates
    reference_status: str = "REFERENCE_BITS_UNAVAILABLE"
    bit_error_rate: Optional[float] = None
    bit_errors: Optional[int] = None
    diagnostics: Dict[str, Any] = field(default_factory=dict)
    warnings: List[str] = field(default_factory=list)
    failure_reason: Optional[str] = None
```

## 5. Phase 2.6 Capabilities: Mapping Profiles & Ambiguity Candidates

### A. Constellation Mapping Profiles
Separates sector/PAM level slicing from bit-label mapping:
- **8-PSK**:
  - `DEFAULT`: Standard Gray code order ($0^\circ \to 000, \dots, 180^\circ \to 110, 225^\circ \to 111, 270^\circ \to 101, 315^\circ \to 100$).
  - `OCTAVE`: GNU Octave `pskmod` Gray order ($180^\circ \to 111, 225^\circ \to 110, 270^\circ \to 100, 315^\circ \to 101$).
- **16-QAM**:
  - `DEFAULT`: Slices PAM-4 levels $\{+3, +1, -1, -3\} \to \{(1, 0), (1, 1), (0, 1), (0, 0)\}$.
  - `OCTAVE`: GNU Octave `qamdemod` order $\{+3, +1, -1, -3\} \to \{(0, 0), (0, 1), (1, 1), (1, 0)\}$.

### B. Candidate Phase Rotations
- BPSK exposes candidates at $0^\circ, 180^\circ$.
- QPSK and 16-QAM expose candidates at $0^\circ, 90^\circ, 180^\circ, 270^\circ$.
- Downstream decoders evaluate these candidates using FEC re-encode consistency without truth data.

### C. 16-QAM Carrier Tracking
- Replaces unit-circle assumption with a true Decision-Directed 16-QAM PLL slicer, eliminating artificial phase error on off-diagonal symbols.

## 6. Integration with Phase 1 Decoder Chain

The demodulator hooks directly into the Phase 1 forward error correction pipeline via `DecoderPipeline.decode()`:

$$\text{Complex IQ Waveform} \xrightarrow{\text{demodulate()}} \text{Candidate Hard Bits} \xrightarrow{\text{decode\_chain()}} \text{Source Bits} \xrightarrow{\text{encode\_chain()}} \text{Re-Encode Consistency Check}$$

- **Self-Consistent Ambiguity Resolution**: Selects the candidate with zero re-encode errors.
- **G5 Golden Path**: 2-FSK demodulator produces recovered coded bits, which feed into `decode_chain` (Convolutional deinterleaver $\rightarrow$ Viterbi $K=7, R=1/2$ $\rightarrow$ RS(255, 223)). Exact 0 errors.
- **G7 Near-Threshold Diagnostics**: QPSK demodulator records safe diagnostics without forcing artificial decoding at 6 dB SNR.
